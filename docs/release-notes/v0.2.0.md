Tonearm's first public release: a native now-playing overlay for OBS Studio on Windows, with four presets, four layouts and optional animated album artwork.

## Download

- **`tonearm-v0.2.0-windows-x64.zip`** is the plugin. Close OBS, extract the zip into your OBS folder (usually `C:\Program Files\obs-studio`) and let Windows **merge** the `obs-plugins` and `data` folders. Then add **Tonearm Now Playing** under Sources.
- `tonearm-v0.2.0-windows-x64-pdb.zip` holds debug symbols. You only need it when reporting a crash.

The plugin zip contains:

```
obs-plugins/64bit/tonearm.dll
data/obs-plugins/tonearm/        effects, fonts, locale, README, LICENSE, NOTICE, CHANGELOG
```

Requires Windows 10 1809 or newer (64-bit) and OBS Studio 30.2 or newer. Full steps are in [Getting started](https://github.com/cxrlosxk/tonearm/blob/main/docs/getting-started.md).

## Highlights

- **Reads any player** in the Windows media flyout, including Apple Music, Spotify, TIDAL, Deezer, foobar2000, MusicBee and VLC. No account or API key.
- **Four presets**, Glass, Minimal, Neon and Editorial, each in compact, expanded, square and vertical layouts.
- **Animated album artwork** (opt-in, off by default). Plays an album's genuine Apple Music motion artwork in place of the still cover, found through an independent lookup service and cached on your PC. *Smart* quality matches the video's resolution to the card's size. The still cover stays whenever there's no video.
- Colors from the artwork with automatic contrast checks, smooth extrapolated progress, considered transitions, a reduce-motion mode, and presets you can export as files.

## Good to know

- The motion artwork lookup is unofficial and not run by Apple or by Tonearm. It can change, and not every album has motion artwork. With the feature on, the artist and album name of the current track are sent to that service; nothing is sent while it's off. See [Animated artwork](https://github.com/cxrlosxk/tonearm/blob/main/docs/animated-artwork.md).
- Live music data works on Windows only for now.

The full list of changes is in the [changelog](https://github.com/cxrlosxk/tonearm/blob/main/CHANGELOG.md).
