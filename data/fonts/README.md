# Bundled fonts

Tonearm ships these fonts unmodified so every preset looks the same on every
machine. All of them are licensed under the SIL Open Font License 1.1, included
here as `OFL-1.1.txt`. The OFL allows bundling with software; the fonts may not
be sold on their own.

| `IBMPlexSans-*.ttf`, `IBMPlexMono-*.ttf` | IBM Plex | Copyright 2017-2018 IBM Corp., with Reserved Font Name "Plex" |
| `EBGaramond12-*.otf` | EB Garamond | Copyright 2010-2012 Georg Duffner (http://www.georgduffner.at) |

The files were taken from the Debian/Ubuntu packages `fonts-inter`,
`fonts-ibm-plex` and `fonts-ebgaramond`.
